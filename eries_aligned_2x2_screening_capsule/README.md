# ERIES-aligned 2x2 pile-group screening capsule

This capsule packages the reproducible evidence objects used by the manuscript.

It is not a final design package. It is a reusable benchmark capsule for claim-governed preliminary screening of a laterally loaded 2x2 pile group.

Core objects:
- fixed 2x2 design-space enumeration;
- selected-candidate canonical results;
- CalculiX p-y and 3D continuum traces;
- CalculiX interface-layer E4 benchmark;
- OpenSeesPy independent p-y implementation check;
- multi-model displacement evidence band;
- V4-S claim passport and Claim Support Index.

Run `python run_all.py` from the full supplementary package root to execute the main QA gates when the manuscript package is available.
